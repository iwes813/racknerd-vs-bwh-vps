## 线路差距的原理：CN2 GIA 到底贵在哪

搬瓦工的溢价有明确的工程账可算。国内访问海外服务器，电信出境主要有几条路径：最普通的 163 网（AS4134）晚高峰丢包率可能到 30% 以上；CN2 GT 转接档 2019 年后也已经和 163 网一样堵；真正的精品线是 CN2 GIA（AS4809），第三方整理的线路单价能到 120 美元/Mbps——1Gbps 满带宽一个月光线路费就是十万美元级别。搬瓦工在洛杉矶 USCA_9 机房部署了 8 条 10Gbps 的 CN2 GIA/CTGNet 链路，并把去程按运营商分流：电信走 CN2 GIA，移动走 CMIN2，联通走 China Unicom Premium。晚高峰稳定靠的是线路等级和冗余，堆带宽解决不了这个问题。

RackNerd 走的是普通国际线路。第三方实测的量级是：白天能跑到 200–400 Mbps，晚高峰降到 30–100 Mbps；洛杉矶 DC02 对国内三网延迟约 150–180ms，晚高峰偶尔抖动但断线少见。这个表现做建站、外贸企业官网、备用节点都没问题，拿它当每晚都要看 4K 的主力代理节点就会失望。顺带一提，RackNerd 的 IP 解锁 Netflix、Disney+ 通常不行，但 ChatGPT、Claude、Gemini 可以正常访问，注册和使用海外 AI 服务反而是它被提及较多的用途。

## 三个下单前才知道的细节

这一节是多数对比文章没讲透、但直接影响使用体验的部分。

**第一，72 小时的免费换 IP 窗口。** RackNerd 购买后 72 小时内可以自助免费更换一次 IPv4，过期之后每次换 IP 收 $3。国内用户拿到机器先 ping 一下 IP，通不了就趁这三天换掉——被墙后的换 IP 成本完全是两个价。

**第二，退款和配置调整的硬限制。** RackNerd 所有 VPS 产品不退款，取消后 24 小时内终止服务并清除数据；年付促销套餐可升级、不可降级；机房开通后不能直接换，只能退订重开。搬瓦工是 30 天无理由退款（退回账户余额），GIA-E 系列还能在 KiwiVM 后台免费一键迁移机房。预算拿不准、想先试后买的用户，这个政策差异本身就值一部分差价。

**第三，搬瓦工自己的“年付折扣”技巧。** CN2 GIA-E 入门档没有月付，最低季付 $49.99；直接选年付 $169.99 折合每月约 $14.17，比季付便宜近 30%。它还有长期可用的全场循环折扣码（约 6.8% 减免，每次续费生效），叠加后入门年付到手约 $158。这些是其官网购买流程里的常规操作，和 RackNerd 的终身同价续费是两种省钱逻辑：一家把便宜放在首年之前，一家把便宜放在每一年。
